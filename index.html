♻️ ECOCLASIFICADOR

Tecnología para reciclar mejor

📖 Instrucciones

  1. 📷 Presiona Iniciar cámara para activar la cámara.
  2. 🔄 Usa Cambiar cámara para cambiar entre cámara frontal y trasera.
  3. ♻️ Coloca el residuo frente a la cámara.
  4. 🧠 EcoClasificador analizará la imagen.
  5. 🗑️ La aplicación mostrará dónde clasificarlo.
  6. 🖼️ También puedes subir una fotografía.
  7. 🔎 Puedes escribir el nombre del residuo en el buscador.

Importante: el resultado es una ayuda para clasificar residuos. Las reglas pueden variar dependiendo del lugar.
